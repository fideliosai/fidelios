# v0.0.55

> Released: 2026-06-13

Fix for `@fideliosai/adapter-hermes-local`: agents using a custom Ollama
provider with an `OLLAMA_API_KEY` secret reference crashed on heartbeat because
the adapter tried to call `.trim()` on the FideliOS secret envelope object.

## Fix: unwrap `OLLAMA_API_KEY` secret envelope

When an agent's `adapterConfig.env.OLLAMA_API_KEY` is stored as a FideliOS
secret reference, FideliOS passes it to the adapter as an object in the form:

```json
{ "type": "plain", "value": "..." }
```

`resolveOllamaApiKey` now detects this envelope and extracts the `value`
before trimming, so custom Ollama endpoints that require an API key work as
expected.

- Updated `resolveOllamaApiKey` in
  `packages/adapters/hermes-local/src/server/execute.js` to unwrap
  `{ type, value }` envelopes and fall back to a string for process-env values.
- Added regression test covering the envelope case.

## Internal

- Changes confined to `packages/adapters/hermes-local/src/server/execute.js`
  and its test file.
