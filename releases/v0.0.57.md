# v0.0.57

> Released: 2026-06-14

Fix for `@fideliosai/adapter-opencode-local`: some `ollama-cloud` models are
advertised without a tag (for example `ollama-cloud/kimi-k2.7-code`) but only
exist in the Ollama Cloud registry with a `:cloud` tag. FideliOS now exposes
the tagged variant during discovery and automatically retries with `:cloud`
when a bare ollama-cloud ID fails at runtime.

## Fix: handle ollama-cloud models that only exist as `:cloud`

- Discovery now exposes both the bare ID and the `:cloud` variant for
  `ollama-cloud` models advertised without a tag.
- Execution retries once with `:cloud` appended when an `ollama-cloud` run fails
  with a model-not-found error, so agents configured with the bare ID still work.
- Added regression tests covering discovery of the `:cloud` variant and the
  runtime retry path.

## Internal

- Changes confined to `packages/adapters/opencode-local/src/server/models.ts`,
  `packages/adapters/opencode-local/src/server/execute.ts`, and their test files.
