# v0.0.56

> Released: 2026-06-14

Fix for `@fideliosai/adapter-opencode-local`: the OpenCode model list was being
read from a local cache, so newly-added models (for example
`ollama-cloud/kimi-k2.7-code`) were not visible in FideliOS until the cache was
manually refreshed.

## Fix: refresh OpenCode model cache during discovery

The adapter now passes `--refresh` whenever it runs `opencode models`, forcing
OpenCode to fetch the current provider/model list from `models.dev` instead of
using a potentially stale local cache. The "no models" error hint has also been
updated to suggest `--refresh`.

- Updated `discoverOpenCodeModels` in
  `packages/adapters/opencode-local/src/server/models.ts` to run
  `opencode models --refresh`.
- Added `packages/adapters/opencode-local/src/server/models-discovery.test.ts`
  regression test verifying the discovery command includes `--refresh`.

## Internal

- Changes confined to `packages/adapters/opencode-local/src/server/models.ts`
  and its test file.
